## `~/` Sobre mim

```console
$ cat sobre-mim.txt
```

Sou **Lestar Henriques**, profissional de dados com atuação em **Engenharia de Dados, Business Intelligence, Data Analytics, automação e desenvolvimento de soluções orientadas a dados**.

Meu trabalho é focado em transformar dados brutos em informações confiáveis, produtos analíticos e ferramentas que apoiem decisões de negócio.

- Desenvolvimento de **dashboards, indicadores e análises de performance**
- Construção e evolução de processos de **ETL / ELT**
- **Modelagem de Dados**
- **Data Analytics**
- **Business Intelligence**
- **Data Visualization**
- **KPI Management**
- **Data Governance**
- **Data Quality**
- **Governança da Informação**
- **Automação de Processos**
- **Performance Analysis**
- **Documentação de Processos**
- Desenvolvimento de aplicações e ferramentas utilizando **Python, Java, Spring Boot, TypeScript e JavaScript**
